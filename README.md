# Artefacto adaptativo v0.1

Prototipo web preliminar de la tesis de Daniel. Demuestra el núcleo de diagnóstico, perfil, práctica y decisiones adaptativas. Su lógica Go se organiza para poder reutilizarla o exponerla a una futura aplicación móvil; esta interfaz Vue solo sirve para demostrarla.

## Estructura

- `backend/domain`: perfil, evidencias, reglas y decisiones.
- `backend/api`: sesiones de demostración y API JSON.
- `frontend`: interfaz mínima en Vue.

La versión v0.1 no constituye una evaluación pedagógica validada ni una aplicación final.
